# xApocalypse 1.7.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add lightweight, restart-safe Blood Moon weather, periodic vanilla scares, and sleep prevention to xApocalypse 1.7.0.

**Architecture:** A new `BloodMoonAtmosphereManager` owns weather snapshots, one global sound deadline, and the internal one-shot scare. `BloodMoonManager` remains the lifecycle authority and calls it from the existing synchronous heartbeat; `xApocalypseListener` handles bed attempts through narrow Blood Moon queries.

**Tech Stack:** Java 25, Maven, Paper API 26.2, Bukkit events and YAML, JUnit 5, Mockito.

## Global Constraints

- Create no additional repeating atmosphere task and no per-player timer.
- Keep all Bukkit world, player, weather, sound, and event calls on the main thread.
- Affect only the exact enabled world that owns the Blood Moon; never affect lobby worlds.
- Cover natural and forced Blood Moons and resume after restart without replaying the start sound.
- Add no particles, potion effects, or resource-pack dependency.
- Make public behavior configurable. Keep the fake-creeper scare out of config, changelog, docs, and player test guides.
- Give the hidden scare a fixed 1% chance per normal cue, one target, and a once-per-event limit that survives restart.
- Preserve and never stage the existing uncommitted `versions/BUILD-TRACKER.md` change.
- Replace redundant generated comments with short why-focused comments without altering unrelated behavior.
- Release version is `1.7.0`; archive the successful build under `versions/2026-11-06/`.

## File Map

- Create `BloodMoonAtmosphereManager.java` for configuration, weather state, cues, scare state, and persistence.
- Modify `BloodMoonManager.java` for lifecycle calls, persistence hooks, and sleep queries.
- Modify `xApocalypse.java` for enable, reload, and shutdown integration.
- Modify `xApocalypseListener.java` for `PlayerBedEnterEvent`.
- Add focused atmosphere, lifecycle, and sleep tests.
- Update public YAML, metadata, and Blood Moon documentation.
- Build and archive the JAR plus its simple live-test guide.

@EventHandler(priority = EventPriority.HIGHEST)
public void onPlayerBedEnter(PlayerBedEnterEvent event) {
    Player player = event.getPlayer();
    if (!bloodMoon.shouldBlockSleep(player.getWorld())) return;
    event.setCancelled(true);

    if (bloodMoon.shouldResetPhantomTimer()) player.setTimeSinceRest(0);
}
